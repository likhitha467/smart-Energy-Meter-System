# Smart Energy Meter System

## Project Overview
The Smart Energy Meter System is an embedded systems project designed to monitor electrical energy consumption and estimate electricity costs. It uses Arduino Uno and Python-based simulation to calculate power, energy consumption, and electricity bills while detecting overload conditions.

## Objectives
- Monitor voltage and current inputs.
- Calculate electrical power.
- Measure energy consumption in kWh.
- Estimate electricity bills.
- Detect overload conditions.
- Display measurement results and status.

## Components and Tools
- Arduino Uno
- DC Voltage Source
- DC Current Source
- Resistors
- 16x2 LCD Display
- Green LED
- Red LED
- Arduino IDE
- SimulIDE
- Python 3
- NumPy
- Matplotlib

## Working 
1. Voltage and current values are provided as inputs.
2. Power is calculated using P = V × I.
3. Energy consumption is accumulated in kWh.
4. Electricity cost is calculated using the tariff rate.
5. Current is compared with the overload threshold.
6. The system indicates normal or overload conditions.

## Python Simulation
Python is used to simulate voltage and current inputs, calculate electrical parameters, and generate graphs for:
- Power consumption
- Energy consumption
- Electricity bill

## Applications
- Smart electricity monitoring
- Home energy management
- Energy consumption analysis
- Embedded monitoring systems
